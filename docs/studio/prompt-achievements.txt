Build a self-contained achievements module for a browser 3D game called "离地 LIFTOFF" (a thruster Roadster: drive a desert highway, hop on thrusters, climb to space, meet the 2018 Starman Roadster in orbit, re-enter). Plain ES modules, no dependencies, no build step. All UI text in Simplified Chinese, code comments in Chinese. Two reference files are attached under context/ (index.html and hud.js) so you can match the existing look: frosted-glass panels (translucent dark background, backdrop-filter blur, 1px light border, 16px radius), white text, accent gradient #ff8a5c -> #ff4d3a, cyan #7fe3ff, gold for achievements #ffd27a.

FILES
- src/achievements/achievements.js
- src/achievements/achievements.css
- src/achievements/demo.html (buttons to fire every event + a reset button)
- src/achievements/README.md (Chinese: API and how to wire it)

API (exact)
export function createAchievements({ storageKey = 'liftoff.achievements.v1' } = {})
returns { report(event, data), update(state), list(), get unlocked, get total, reset(), openPanel(), closePanel(), onUnlock(fn) }
- report(event, data): discrete game events. Event names: 'drive_start', 'launch_time' {seconds}, 'airborne', 'hover10', 'land', 'boom', 'clouds', 'stratosphere', 'karman', 'orbit', 'meet', 'reentry_home', 'ascent_abort' {fuelEmpty:boolean}, 'camera' {mode} (modes: chase, low, cine, cockpit, free), 'screenshot', 'horn'.
- update(state): called every frame with { speedKmh, distanceKm, offroad (0..1), hops (count this session), altitudeM, mode }. Use it for threshold achievements.
- Unlocks persist in localStorage (try/catch; must work when storage throws). Counters that span sessions (e.g. number of orbits) also persist.
