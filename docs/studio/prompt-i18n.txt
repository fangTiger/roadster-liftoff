API (exact, all named exports)
- LANGS = ['zh', 'en']
- t(key, vars?) -> string. Look up the current language; fall back to zh, then to the key itself. Replace {name} placeholders from vars; leave unknown placeholders untouched.
- getLang() -> 'zh' | 'en'
- setLang(lang): ignore unknown values; persist to localStorage key 'liftoff.lang.v1' (wrap in try/catch, must work when storage throws); set document.documentElement.lang to 'zh-CN' or 'en'; call applyI18n(document); notify listeners. No-op if unchanged.
- onLangChange(fn) -> unsubscribe function.
- applyI18n(root = document): elements with data-i18n="key" get textContent = t(key); data-i18n-html="key" get innerHTML = t(key) (only used for our own dictionary strings containing <kbd>); data-i18n-attr="aria-label:key;title:key2" sets each attribute.
- mountLangToggle(container): if container is null do nothing. Append one element to the container: <span class="lang-toggle" role="button" tabindex="0"> showing "中 / EN" with the current language highlighted (bold white) and the other dimmed. Click, Enter or Space switches to the other language (Enter/Space: preventDefault + stopPropagation so the game does not see the key). aria-label and title from t('lang.toggle'), refreshed on language change. Calling it twice must not add a second toggle.
- Initial language when the module loads: saved value in localStorage if valid; otherwise navigator.languages (or navigator.language): if any entry starts with "zh" -> 'zh', else 'en'. Must not throw in Node (no window/navigator/document) — default to 'zh' there. Set document.documentElement.lang at load when document exists.
