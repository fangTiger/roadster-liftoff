Build a self-contained "run summary + share card" module for a browser 3D game called "Mars Roadster" (Chinese subtitle 离地: a white thruster Roadster drives a curving desert highway, collects gold coins, hops on thrusters, climbs through the clouds to space, meets the 2018 Starman Roadster in orbit, and re-enters back to the road). Plain ES modules, no dependencies, no build step, no network requests. All UI text in Simplified Chinese, code comments in Chinese.

Reference files are attached under context/: index.html (the game page, copy its look), logo.svg (the game logo, top-view white car pointing up with two flames on an orange-red rounded tile), achievements.css (an existing module styled to match). Match the look: frosted-glass panels (rgba(14,16,22,.42) background, backdrop-filter blur(14px) saturate(150%), 1px rgba(255,255,255,.14) border, 16px radius), white text, dim text rgba(244,246,250,.6), accent gradient #ff8a5c -> #ff4d3a, cyan #7fe3ff, gold #ffd36a for coins.

API (exact)
export function createShare({ logoUrl = '/logo.svg', author = 'Captain@mycndota', siteUrl = '', credit = 'Built with Arc Studio + Claude Code' } = {})
returns { open(stats, screenshot), close(), get isOpen, onClose(fn), renderCard(stats, screenshot, format) }
- open(stats, screenshot): shows the summary panel. screenshot is an HTMLCanvasElement, HTMLImageElement, ImageBitmap or a data URL string (may be null -> use a dark space gradient background).
- close(): hides it; onClose callbacks fire (the game resumes input after this).
- renderCard(stats, screenshot, format): returns Promise<HTMLCanvasElement>, format 'landscape' (1200x630) or 'portrait' (1080x1350). Exported so the game can reuse it.
- Also export the pure helpers used by the card and tests: formatAltitude(m), formatDuration(sec), formatSpeed(kmh), pickHeadline(stats), formatDate(date).

stats object (all optional, missing values shown as "—")
{ topSpeedKmh, launchSec (best 0–100 km/h time, seconds), maxAltM, distanceKm, coins, hops, flightSec (seconds airborne/in flight), reachedSpace (bool), metOldFriend (bool), home (bool, re-entered and landed), achievements: { unlocked, total }, date (Date, default now) }

Formatting rules
- formatAltitude: < 1000 m -> "850 m"; < 10 km -> "3.4 km"; otherwise "412 km" (rounded).
- formatSpeed: integer with thousands separator + " km/h" (e.g. "27,600 km/h").
- formatDuration: "42 秒", "3 分 05 秒".
- launchSec: two decimals + " 秒" (e.g. "0.82 秒").
- pickHeadline(stats) returns { title, value } for the big hero line, first match wins:
  home -> { title: '往返太空，安全返航', value: formatAltitude(maxAltM) }
  metOldFriend -> { title: '在轨道上与前辈同框', value: ... }
  reachedSpace -> { title: '冲出大气层', value: ... }
  maxAltM >= 450 -> { title: '穿出云层', value: ... }
  hops > 0 -> { title: '离地起飞', value: ... }
  else -> { title: '沙漠公路', value: formatSpeed(topSpeedKmh) }

SUMMARY PANEL (DOM)
- Full-screen dimmed backdrop, centered frosted-glass card (max 760px wide; stacks to one column under 640px; must fit a 390x844 phone without horizontal scroll).
- Header: logo image + "Mars Roadster" + small "本局成绩" + the date.
- Hero: headline title and big value.
- Stat grid (2x3 or 3x2): 极速 / 0–100 用时 / 最高海拔 / 里程 / 金币 (gold coin dot) / 成就 n/total.
- Badge row for reachedSpace / metOldFriend / home ("进入太空" "与前辈同框" "安全返航"), unearned badges dimmed.
- Live preview of the share card image (rendered with renderCard) with a 横版 / 竖版 toggle.
- Buttons: 保存图片 (download PNG named mars-roadster-YYYYMMDD-HHMM.png), 分享 (navigator.share with the PNG file; only show when navigator.canShare({files}) is true), 复制图片 (ClipboardItem; only show when supported; show "已复制" feedback), 继续驾驶 (close, primary button).
- Keyboard: Escape and Enter close; focus trapped inside while open; restore focus on close. Clicking the backdrop closes.
- While open, stop keydown events from reaching the game (stopPropagation in capture phase on window for keys other than browser shortcuts).
- Respect prefers-reduced-motion. Small entrance animation otherwise.

SHARE CARD (canvas)
- Background: the screenshot drawn "cover" style; a dark gradient from the left (landscape) or bottom (portrait) so text stays readable.
- Top-left: logo (64px tile) + "Mars Roadster" bold + "离地" smaller.
- Headline title + huge value (e.g. "412 km"), then the stat grid in a frosted rounded box (draw it, no CSS on canvas).
- Badges as small pills.
- Footer line, small and dim: "作者 {author} · {credit}" and the date; if siteUrl is non-empty append it.
- Use system fonts: -apple-system, "PingFang SC", "Microsoft YaHei", sans-serif. Wait for the logo image to load (time out after 2 s and draw without it). Use devicePixelRatio-independent fixed sizes. Never taint the canvas (logo is same-origin; screenshot may be a canvas).

QUALITY

- Tests cover all formatters and pickHeadline order.
- Do not deploy anything, do not create keys or .env files, no wallet or blockchain code. Reply with the file list and anything you could not do.
