# 音频需求与场景

- 工厂返回规定的 unlock、cue、update、event、setMuted、toggleMuted、setVolume 和 muted getter；创建及解锁前调用均不得播放。
- 首次手势中创建/恢复上下文并播放 road；重复解锁不重建节点、不重置当前歌曲，失败可重试。
- road、space 循环，oldfriend 单次播放结束回到 space；重复当前 cue 无操作；快速连续切换保持增益连续，等功率切换历时 2.5 秒。
- 音乐按速度滤波与增强、推进器压低、爬升高通及混响、轨道声像及 -3 dB、再入 -8 dB 调整；着陆后混响在约 3 秒回干。
- 合成电机、路面、碎石、风、推进器、等离子体及全部五类一次性事件；轨道中电机/路面/风静音。
- 持续节点及噪声缓存复用，一次性节点结束后断开；所有动态参数平滑变化；独立音乐/音效增益及末端压缩器。
- 静音和音量持久化，存储异常不中断；错误 URL 和播放拒绝可观察，无未处理 Promise 拒绝。
- 演示页可控制所有字段、模式、音乐和事件，使用指定的三个 MP3；模块和页面不依赖 npm 或构建。
- node 语法检查通过；自动化验证解锁、切换、混音、事件清理、持久化及逐帧节点数量。
