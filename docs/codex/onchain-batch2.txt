你在 Mars Roadster 仓库里实现「往返纪念 NFT」的网站接口（部署在 Vercel，项目根目录的 api/ 会成为 Vercel Functions，Node 运行时）。先读 openspec/changes/add-arc-onchain-records/ 的 proposal.md、design.md、spec.md，以及上一批已经写好的 src/chain/config.js、src/chain/records.js（复用里面的 ABI、formatMs、shortAddr、bitsToCount，别重复实现；若它们依赖 import.meta.env，就把纯常量部分抽到一个两边都能 import 的文件里）。

合约 MarsRoadsterRecords（ERC-721，不可转让，每钱包一枚）：tokenURI(id) = "https://mars-roadster.vercel.app/api/nft/" + id。
  recordOf(address) returns (Record { uint32 tokenId; uint32 bestMs; uint32 achievements; uint40 mintedAt; uint40 updatedAt; })
  ownerOf(uint256) returns (address)（不存在的 tokenId 会 revert）
  totalSupply() returns (uint256)

要做的事：
1. api/nft/[id].js —— GET 返回 ERC-721 元数据 JSON：
   { name: "Mars Roadster Round Trip #0001", description, image, external_url: "https://mars-roadster.vercel.app", attributes: [
     { trait_type: "Round trip", value: "46.83 s" }, { trait_type: "Round trip (ms)", value: 46830, display_type: "number" },
     { trait_type: "Achievements", value: 12, max_value: 20, display_type: "number" }, { trait_type: "Minted", value: <unix 秒>, display_type: "date" },
     { trait_type: "Network", value: "Arc Testnet" 或 "Arc" } ] }
   description（英文）说明：完成一次地面→轨道→地面往返的纪念；成绩为玩家自报；不可转让；Mars Roadster 是非商业粉丝致敬作品，与 Tesla、SpaceX 无关联。
   image = `${SITE_URL}/api/nft/image/${id}?v=${updatedAt}`（成绩更新后图片地址变化，绕过各方缓存）。
   id 非正整数 → 400；token 不存在 → 404 JSON。响应头 Cache-Control: public, s-maxage=60, stale-while-revalidate=300；Access-Control-Allow-Origin: *。
2. api/nft/image/[id].js —— GET 返回 1024×1024 PNG，用 @vercel/og 的 ImageResponse（已安装）：
   - 底图：${SITE_URL}/assets/nft/base.jpg（2048 方图，铺满）。
   - 顶部左上：小号字距拉开的 "MARS ROADSTER"，下面 "ROUND TRIP  #0001"。
   - 底部一条科技感半透明深色信息栏（细的高光描边、轻微渐变、等宽数字）：大号往返用时（如 46.83 s）为主角；旁边三列小标签 + 数值：ACHIEVEMENTS 12/20、MINTED 2026-10-27、PILOT 0x81d4…707B；最底一行极小字 "SELF-REPORTED · NON-TRANSFERABLE · ARC TESTNET"（主网为 ARC）。
   - 只用英文和数字（默认字体即可，不要中文）。整体要大气、克制、有科技感，不要花哨的颜色，主色白色 + 冷蓝色细节。
   - 不存在的 token 返回 404；缓存头 public, s-maxage=86400, immutable（地址带 v 参数）。
3. 两个接口共用 api/_lib/chain.js：用 viem 的 publicClient（http RPC）读链；网络与合约地址来自服务器环境变量 ARC_NETWORK（testnet|mainnet，默认 testnet）、RECORDS_ADDRESS、SITE_URL（默认 https://mars-roadster.vercel.app）。读链函数可注入，便于测试。以 _ 开头的目录不会成为路由。
4. 函数导出方式用 Web 标准：export async function GET(request) { return new Response(...) }。
5. 测试 api/nft.test.mjs（node --test）：注入假读链函数，覆盖元数据字段、400/404、image 地址带 v、缓存头。图片接口至少测 404 与 content-type。
6. 本地自检脚本 scripts/nft/preview.mjs：用假数据直接调用图片接口的 GET，把 PNG 写到 recordings/nft-preview.png（底图从本地 public/assets/nft/base.jpg 读成 data URL，通过可选参数注入，避免依赖线上站点）。运行它并确认生成了图片。

要求：注释中文、标识符英文；不改 src/ 下与本任务无关的文件；不部署、不创建密钥或 .env、不安装新依赖、不 git commit。完成后运行 node --test（全部测试文件）和 npx vite build，都必须通过。最后用中文回复：文件列表、测试与构建结果、预览图路径、没做到的事。
