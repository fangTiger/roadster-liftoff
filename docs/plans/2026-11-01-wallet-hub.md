# 钱包中心实施计划

目标：落实已批准的 `add-wallet-hub`，保持现有钱包单例与赛车行为。

架构：`wallet.js` 统一状态与操作，连接适配器把断开转交 wagmi。`nft-card.js` 负责链上读取、会话失效保护与卡片；`wallet-hub.js` 负责入口、菜单和对话框；成绩面板在确认后展示成功。

技术：原生 DOM、viem/wagmi、node --test、Vite、Playwright。

1. 为主动断开、切链补失败测试；补齐 wallet 与现有连接桥，执行钱包测试。
2. 为卡片的空状态、三赛道数据、图片降级、旧会话竞态补失败测试；实现共享卡片。
3. 为钱包入口、菜单、对话框关闭与语言同步补失败测试；实现组件并在首页及赛车入口挂载，复用卡片到排行榜。
4. 为首次铸造、更新、失败及刷新竞态补失败测试；实现成功状态及 3.6 秒提示，避让成就提示。
5. 执行全部测试、构建和严格 spec 校验，使用已运行的 8932 服务截图核查宽窄屏、驾驶与房间布局。
6. 对照需求审查，勾选 1.1–1.5，保持 2.x 未勾选；仅提交相关文件，中文提交信息，不推送。
