# 多人开局加载门修复计划

**目标：** 恢复 live-rooms 的统一倒计时与发车要求，不修改物理、录像或 SIM_VERSION。

**设计：** 服务端先广播 `startAt:null` 的 start，等待在线真人 loaded，最多 20 秒；再广播当前时间加 1000ms 的 go。客户端加载后停在发车格，HUD 显示双语进度；go 提前到达时保留时刻，加载完沿用追帧。恢复连接复用同局会话并同步最新时刻。

**技术：** 原生 JavaScript、Node test runner、Vite、OpenSpec。
