# 机器人再提升两档实施计划

**目标：** 三档目标分别为草甸 34.8 / 32.0 / 29.5 秒、湖畔 36.1 / 33.2 / 30.5 秒、阿尔卑斯 63.7 / 58.5 / 54.0 秒。

**架构：** 简单继承旧困难赛车线与分图倍率；普通、困难通过既有 `botPerformance` 显式传递引擎、极速、抓地倍率，按地图校准弯速与制动。只改机器人控制器及验收工具，不改真人物理、录像、模拟版本或核验。

**技术：** JavaScript ES modules、Node test、固定 120Hz 会话、OpenSpec、Vite。

## 步骤

1. 更新 `openspec/changes/accelerate-personalize-bots` 三档目标和验收场景；补充 `src/race/bot-driver.test.mjs` 参数与分图三种子三圈目标失败测试，运行确认 RED。
2. 调整 `src/race/bot-driver.js` 的三档参数与分图校准，逐图运行真实会话，统计平均、最快、墙事件、碰撞、重置、掉落及最长低速；在测试保护下校准至稳定。
3. 更新 `scripts/race/benchmark-bots.mjs`，默认每种子三圈，第二、三圈计飞驰圈平均，首圈单列，固定种子 11 / 29 / 47；保留困难十圈、三图正反出生位六车三圈及真实道具赛。
4. 检查房间下拉和展台文案与中英词条；有具体行为说明则同步，纯难度名称保持。
5. 向 `docs/plans/2026-10-31-bot-results.md` 追加新实测表与稳定性证据，更新 tasks 状态。
6. 执行 `npm test`、录像/核验定向测试、`npx vite build`、OpenSpec strict、语法与 diff 检查；审查后仅暂存本任务文件，用中文提交，不推送、不部署。

## 验收口径

每图每档三个种子各三圈，100% 完赛；飞驰圈平均在目标 ±0.8 秒内（阿尔卑斯 ±1.5 秒），逐图简单 > 普通 > 困难。报告全部九圈墙事件与接触次数，禁止卡死、重置、掉落和深入捷径；道具强制失控与可控低速分开统计。高倍率如引发频繁擦墙则优先降倍率、增加制动安全余量。

## 执行结果

- 已完成 RED → GREEN：三档映射、三图倍率与速度目标、水泥墩循迹、落石反打、低冲击几何接触监测。
- 实测累计 90 台次、291 圈全部完赛；最长连续几何接触 0.783 秒，可控最长低速 0.883 秒。
- 全量测试 605/605、录像及核验定向 33/33、生产构建与 OpenSpec strict 均通过。
- 独立审查发现并修复墙事件无法覆盖轻蹭的验收缺口，复核无遗留实际缺陷。
- 原下拉、展台与中英词条仅有难度名称，不含具体速度说明；保留三档名称且贯通测试通过。
- 完整新表与原始种子圈速见 `docs/plans/2026-10-31-bot-results.md` 的“再提升两档”一节。
