# 三档机器人实施计划

**目标：** 简单 / 普通 / 困难仅使用 easy / normal / hard，依次继承 6785ffa 的普通 / 困难 / 最高档，保留对应赛车线、个性、道具及性能倍率。

**方案：** 直接迁移三组参数及条件，不提供旧最高档别名；服务端统一拒绝旧请求。单人房间复用同一三档选择器与房主模拟路径，展台名牌复用中英词条。

**技术栈：** JavaScript、Node 测试、Vite、OpenSpec。

1. 先更新现有 OpenSpec 提案、需求和任务；无需新建重复提案。
2. 先将参数映射、三图倍率、旧请求拒绝、三档 UI / 中英和聪明道具测试改为目标行为；运行定向测试确认预期失败。
3. 迁移驾驶预算、少量失误、反应延迟、赛车线和道具条件；删除旧最高档界面及词条；更新测速脚本三档范围和六车阵容。
4. 运行定向回归和测速，更新三图平均 / 最快及加成说明；历史多车数据明确为旧阵容，避免冒充新测。
5. 运行 npm test、npx vite build、OpenSpec strict、语法及差异检查；审查修改后在 phase1-ghost 中文提交，附指定 Co-Authored-By，不推送部署。
