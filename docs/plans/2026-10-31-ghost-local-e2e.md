# 录像赛本地端到端实施计划

**目标：** 在 phase1-ghost 分支完成测试网录像赛的本地核实、存储和浏览器联调工具，真实签名交易留给审查者运行。

**架构：** 复用 Web Request/Response 处理函数，通过 Node 原生 HTTP 适配；现有 Blob 存储接口按 GHOST_STORE=file 切换到本地文件。开发自动驾驶逐物理步调用 hard 机器人，仍生成正式录像并接受原有服务端重放；生产编译剔除开发入口。

**技术栈：** Node.js、node:test、Vite、Playwright、viem。

## 实施顺序

1. 更新已有 add-ghost-race 规范，增加 128 KB、本地存储、开发自动驾驶和脚本约束。
2. 先修改默认地址、资格线和请求大小测试，运行确认失败，再同步实现与文档。100 KB 请求必须进入正常核实流程，128 KB 上限同时按声明长度及真实流字节验证。
3. 新增文件存储测试：持久化、大小写、隔离、缺失、并发只保留最快和路径校验；先失败，再实现存储切换和原子写入。
4. 新增 HTTP 适配测试：核实 POST 流、影子 GET、NFT 三类路由、404/405、异常脱敏；先失败，再实现服务与开发代理。Vite 禁止读取 .env。
5. 新增自动驾驶录像重放和生产构建排除测试；先失败，再在 DEV 且 URL 开关开启时引入确定性 hard 驾驶器。观察影子创建与实际步进，不更改物理规则。
6. 新增端到端脚本和模拟 RPC 测试，复用受限注入钱包；每步输出状态及交易哈希，失败截图。提供无私钥的 --before-wallet 模式，验证选图、三圈、连接按钮前的页面流程。
7. 更新使用文档及 tasks.md，3.2 保持未完成。运行 npm test、npx vite build、OpenSpec 校验与无私钥浏览器验证，审查差异后中文提交并附共同作者。不推送、不部署。

## 验收边界

- 不访问任何私钥目录或 .env；私钥只由审查者在运行时通过环境变量注入，工具错误输出不包含原始异常。
- 本次不运行签名或测试网交易。真实测试网 verified=true 与独立无钱包上下文下载同场由审查者执行后确认。
- 本地文件写入在单进程内按路径串行、原子替换；线上仍使用 Blob 条件写入。
