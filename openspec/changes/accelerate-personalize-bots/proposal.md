# 机器人提速与驾驶个性

为派对赛和单人对机器人模式提供依次递增的三档机器人，以及每车独立、可复现的走线和速度性格。先测量仅驾驶策略的提速，再按必要程度提供显式可选的机器人性能倍率。

简单、普通、困难分别继承提交 6785ffa 的普通、困难、最高档驾驶预算；草甸目标约 41、37–38、34–35 秒。内部仅保留 easy / normal / hard，旧最高档请求直接返回 BAD_MESSAGE。

普通、困难保留完整赛车线和聪明道具策略。普通仅阿尔卑斯启用必要倍率，困难仅湖畔和阿尔卑斯启用必要倍率。房间白名单、单人房间、下拉框、展台名牌和中英翻译统一三档；报告保留映射后的三图实测平均与最快。

不修改玩家调校、模拟版本及默认自动驾驶结果；机器人不进入链上成绩。保留现有房主模拟与状态广播机制。
