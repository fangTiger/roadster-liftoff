## ADDED Requirements

### Requirement: 首次资格圈纪念 NFT
系统 SHALL 允许首次在资格线内跑完一圈的钱包在 Arc 上铸造一枚灵魂绑定纪念 NFT；每个钱包最多一枚，NFT 记录首圈的赛道、用时和时间，之后不再改变。

#### Scenario: 首次铸造
- **WHEN** 未持有 NFT 的钱包提交一个不超过该赛道资格线的单圈
- **THEN** 合约铸造一枚新编号的 NFT，记录首圈，并把该成绩记为此赛道最快单圈

#### Scenario: 未进资格线
- **WHEN** 未持有 NFT 的钱包提交超过资格线的单圈
- **THEN** 交易被拒绝，不铸造 NFT

#### Scenario: 不能重复铸造
- **WHEN** 已持有 NFT 的钱包再次提交
- **THEN** 不铸造新 NFT，首圈记录不变，只更新最快单圈和成就

#### Scenario: 不可转让
- **WHEN** 任何人调用转让或授权函数
- **THEN** 交易被拒绝

### Requirement: 赛道最快单圈
系统 SHALL 按（钱包，赛道）保存最快单圈，只在新成绩更快时更新，并拒绝低于作弊下限或赛道未开放的提交。

#### Scenario: 成绩更快
- **WHEN** 持有 NFT 的钱包提交短于其该赛道最快单圈的用时
- **THEN** 最快单圈更新为新用时

#### Scenario: 成绩过快
- **WHEN** 提交的用时低于该赛道作弊下限
- **THEN** 交易被拒绝

#### Scenario: 下限只能调高
- **WHEN** 合约管理员尝试把某赛道的作弊下限调低
- **THEN** 交易被拒绝

#### Scenario: 赛道未开放
- **WHEN** 提交的赛道资格线为 0
- **THEN** 交易被拒绝

### Requirement: 服务器签名核实（预留）
合约 SHALL 支持设置核实者地址；设置后，每次提交必须附带核实者对（玩家、赛道、用时、成就、截止时间）的有效签名，并标记该成绩已核实。

#### Scenario: 未设置核实者
- **WHEN** 核实者地址为空
- **THEN** 提交不需要签名，成绩标记为未核实

#### Scenario: 签名无效或过期
- **WHEN** 已设置核实者，而提交的签名不匹配或已过截止时间
- **THEN** 交易被拒绝

## MODIFIED Requirements

### Requirement: 链上成就记录
系统 SHALL 以 32 位位图为每个持有 NFT 的钱包记录已解锁的成就，只增不减；当前使用第 0–27 位。

#### Scenario: 合并新成就
- **WHEN** 持有 NFT 的钱包提交包含新成就的位图
- **THEN** 链上位图与之按位或合并，已有成就保留

#### Scenario: 无可更新内容
- **WHEN** 提交的用时不更快且没有新成就
- **THEN** 交易被拒绝

### Requirement: 游戏内铸造与更新
游戏 SHALL 在竞速模式赛后成绩面板提供连接钱包并铸造或更新链上记录的入口，且没有可更新内容时不发交易。

#### Scenario: 进入资格线且未持有 NFT
- **WHEN** 本局最快单圈不超过资格线，且连接的钱包未持有 NFT
- **THEN** 面板显示「铸造首圈纪念 NFT」，成功后显示区块浏览器链接

#### Scenario: 未进资格线且未持有 NFT
- **WHEN** 本局最快单圈超过资格线，且钱包未持有 NFT
- **THEN** 面板显示资格线与差距，不显示铸造按钮

#### Scenario: 无可更新内容
- **WHEN** 钱包已持有 NFT，本局成绩不比链上更快且没有新成就
- **THEN** 面板提示链上记录已是最新，不发起交易

#### Scenario: 交易失败
- **WHEN** 余额不足、用户取消或网络错误
- **THEN** 面板显示对应原因，游戏继续正常运行

### Requirement: 链上记录面板
游戏 SHALL 提供链上记录面板，显示玩家自己的首圈 NFT、各赛道最快单圈、链上成就数（n/28），以及沙漠环线排行榜前 50 名，并标注为玩家自报成绩。

#### Scenario: 查看排行榜
- **WHEN** 玩家打开链上记录面板
- **THEN** 显示按最快单圈升序排列的前 50 名（钱包缩写、用时、日期），并注明「玩家自报成绩」

### Requirement: NFT 元数据与图片
网站 SHALL 为每枚 NFT 提供元数据、静态图和动态展示页，内容为首圈用时、最快单圈、赛道名和成就数。

#### Scenario: 钱包读取 NFT
- **WHEN** 钱包或区块浏览器请求某枚 NFT 的元数据
- **THEN** 返回名称（含至少四位补零编号）、描述（含玩家自报、不可转让和非隶属声明）、静态图地址、动态展示页地址和属性（赛道、首圈用时、最快单圈、成就数、铸造日期、网络）

#### Scenario: 成绩更新后图片变化
- **WHEN** 持有者更新了最快单圈
- **THEN** 之后请求的静态图和展示页显示新的最快单圈，首圈用时不变

#### Scenario: 无效或不存在的编号
- **WHEN** 请求编号不是正整数字符串，或 NFT 不存在
- **THEN** 元数据、静态图与展示页接口分别返回 JSON 400 或 JSON 404；RPC 故障返回不缓存的 JSON 503

## REMOVED Requirements

### Requirement: 往返纪念 NFT
**Reason**: 往返用时基本固定、拉不开差距，纪念 NFT 改为按赛道首次资格圈发放。
**Migration**: V1 合约只部署在测试网，直接作废；由「首次资格圈纪念 NFT」取代。

### Requirement: 往返最快成绩
**Reason**: 排行榜改为按赛道最快单圈。
**Migration**: 由「赛道最快单圈」取代；太空往返模式保留，但不再上链计时。
