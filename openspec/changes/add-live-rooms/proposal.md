# Change: 实时房间——多人联网同场竞速（路线阶段 2）

## Why
影子赛只能和录像比，缺少真正的对手。确定性物理、按键录像和影子车渲染都已就绪，可以在此基础上做「联网同场」：几位玩家进同一个房间，在各自的画面里看到彼此的车，一起倒计时发车、贴身较量、按冲线顺序排名。这是接下来的重点方向。

## What Changes
- 新增房间服务（独立 Node 进程，WebSocket）：建房、房间码或链接加入、准备、房主选图、统一倒计时、转发车辆状态、汇总名次、断线与重连。
- 新增前端联网模块：时钟校准、按固定频率上报自己车辆的状态、接收其他车辆并做插值和外推。
- 新增房间大厅界面：昵称、房间码、玩家列表、准备状态、房主选图；比赛中显示实时名次和玩家名牌；终点显示结算页。
- 新增软碰撞：两车贴身时轻推分开并掉速；追尾方掉速更多；推力只分开不加速；发车后 3 秒、重置后 2 秒内不碰撞（车身半透明）。每台电脑只修改自己的车。
- 多车发车格：按房间内的座位号错开发车位置。
- 单人模式、影子赛、链上提交流程保持不变：单人录像格式和 SIM_VERSION 不改，golden 回归测试继续通过。
- 第一版房间赛成绩不上链，也不进排行榜。

## Impact
- Affected specs: live-rooms（新增）
- Affected code:
  - server/rooms/（新增房间服务）；
  - src/net/（新增：联网客户端、时钟、插值）；
  - src/race/（大厅、多车渲染、名次 HUD、结算、发车格）；
  - src/race/sim/（新增软碰撞函数，session 增加可选的「外部车辆」参数，默认关闭）；
  - vite 配置（把开发代理 /rooms 转给本地房间服务）。
- 新增依赖：ws（仅房间服务使用）。
- 上线时需要一个能长期保持连接的托管服务（Vercel 普通函数不能保证同一房间的玩家连到同一实例）。选型放到上线阶段，届时请用户确认。本阶段只在本地跑。
