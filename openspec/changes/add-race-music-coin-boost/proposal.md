# Change: 比赛背景音乐与道具赛金币提速

## Why
比赛中没有背景音乐，只有大厅有，节奏感不足。多人道具赛里的金币只给推进器补燃料，而只有阿尔卑斯能开推进器，所以在多数地图上吃金币没有任何作用。

## What Changes
- 所有竞速比赛（单人计时、影子赛、多人竞速赛与道具赛）加入背景音乐《Rush》（Of Far Different Nature，CC-BY 4.0，致谢写入 CREDITS.md）。
  - 倒计时结束发车时淡入，循环播放；暂停时压低，结算时淡出，回到大厅交还给大厅音乐。
  - 音乐整体作为背景铺底，压低中高频；点燃推进器、漂移、氮气加速、被道具击中时自动避让，降低约一半音量，结束后平滑恢复。
  - 沿用现有的音乐开关与静音设置。
- 多人道具赛新增「金币提速」：
  - 每枚金币使极速 +1%，最多叠加 10 枚；被导弹或水雷击中时掉落一半（向下取整）。
  - 名次越靠后，吃金币补充的推进剂越多（最后一名为 2 倍），帮助落后者追赶。
  - 效果必须一眼可见：HUD 金币计数（n/10）、拾取时弹出 +1、车尾流光随金币数增强、被击中时金币从车身四散飞出并显示 -n；其他玩家车尾流光同样随其金币数变化。
  - 仅在多人道具赛生效；单人计时、影子赛与竞速赛的模拟、录像、核实与 SIM_VERSION 均不变。

## Impact
- Affected specs: circuit-race（比赛背景音乐）、party-race（道具赛金币提速）
- Affected code: `src/audio/`（比赛音乐与避让）、`src/race/`（HUD、车尾流光、房间状态同步、道具命中）、`src/race/sim/`（仅道具赛启用的金币计数与极速加成）、`public/assets/music/`、`CREDITS.md`
- 上线需同时更新 AWS 房间服务（如协议字段变化）与 Vercel 生产环境，部署前征得用户同意
