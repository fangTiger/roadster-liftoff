## MODIFIED Requirements
### Requirement: NFT 元数据与图片
网站 SHALL 为每枚 NFT 提供元数据、静态图和动态展示页，内容为首圈用时、最快单圈、赛道名、成就数和等级；外观 SHALL 按首圈赛道选用该赛道专属底图，并按该赛道链上最快单圈判定金、银、铜三档等级，套用对应的边框、配色和徽标。

#### Scenario: 钱包读取 NFT
- **WHEN** 钱包或区块浏览器请求某枚 NFT 的元数据
- **THEN** 返回名称（含至少四位补零编号）、描述（含成绩是否经服务器核实、不可转让和非隶属声明）、静态图地址、动态展示页地址和属性（赛道、等级、首圈用时、最快单圈、成就数、铸造日期、网络）

#### Scenario: 按赛道区分底图
- **WHEN** 请求首圈在草甸、湖畔或阿尔卑斯的 NFT 静态图或展示页
- **THEN** 使用该赛道的专属底图；未知赛道使用通用底图

#### Scenario: 等级判定
- **WHEN** 该赛道链上最快单圈不超过金级线、不超过银级线或高于银级线
- **THEN** 分别显示金、银、铜等级；没有最快圈记录时按首圈用时判定

#### Scenario: 成绩更新后图片变化
- **WHEN** 玩家在首圈赛道上传更快的最快单圈
- **THEN** 之后请求的静态图和展示页显示新的最快单圈与对应等级，首圈用时和底图不变

#### Scenario: 核实状态
- **WHEN** 该赛道最快圈已由服务器核实
- **THEN** 静态图底部显示 VERIFIED，元数据描述写明成绩经服务器核实；未核实时显示 SELF-REPORTED

#### Scenario: 无效或不存在的编号
- **WHEN** 请求的编号格式无效或尚未铸造
- **THEN** 元数据、静态图与展示页接口分别返回 JSON 400 或 JSON 404；RPC 故障返回不缓存的 JSON 503
