# Design: NFT 赛道与等级外观

## 数据来源
- 赛道：`record.firstTrack`（铸造时写入，永不改变）。
- 等级：`bests(owner, firstTrack).bestMs`；没有最快圈记录时用 `record.firstLapMs`。
- 等级线：`RACE_TRACKS` 每项新增 `tiers: { goldMs, silverMs }`。`bestMs <= goldMs` 为金，`<= silverMs` 为银，其余为铜（铸造本身已要求进入资格线）。
- 定稿值以困难机器人圈速为基准：金 = ×1.08，银 = ×1.3，即草甸 32 / 38 秒、湖畔 33 / 40 秒、阿尔卑斯 58 / 70 秒（依据见 tier-calibration.md）。
- 等级判定写成纯函数 `nftTier(trackId, bestMs)`，元数据、静态图、展示页、个人主页共用。

## 底图
- `public/assets/nft/track-1.jpg`、`track-2.jpg`、`track-3.jpg`，1080×1080，JPEG，每张不超过 250KB。
- 由 `scripts/nft/render-tracks.mjs` 在本地竞速场景中逐帧推进到预设取景点渲染：每条赛道选一个最有辨识度的位置，车辆入画，不出现 HUD；画面上方留出放标题的暗部。
- 本次取景：草甸主线约 950m，低机位前斜侧，隐藏截图中的金币网格；湖畔约 1530m，大弯斜侧、山谷黎明；阿尔卑斯约 1440m，断桥飞越的后斜侧。三张图均隐藏 HUD 和金币、顶部压暗；底图分别为 104190 / 125595 / 179237 字节（约 104KB / 126KB / 179KB）。
- **截图布景说明：** 当前三条赛道共用高山草甸场景，湖畔原场景没有湖面。为满足 NFT 中明显可见湖面的要求，仅截图进程加载 `scripts/nft/capture-lake.mjs`：克隆渲染地形构造湖盆、移除湖内植被实例、加入反光水面，所有水面顶点与道路/路肩保持至少 10m 净空。不改赛道定义、物理高度场或游戏逻辑；不把此布景表述为现有游戏地形。
- `base.jpg` 保留，作为未知赛道的兜底。

## 等级样式
三档边框均为原创手写 SVG（1024×1024，中心透明），只借鉴随等级增加装饰层级的思路，不使用或复制现有游戏图案、素材。源文件位于 `scripts/nft/frames/frame-{gold,silver,bronze}.svg`，由 `scripts/nft/render-frames.mjs` 使用 sharp/librsvg 渲染为同名透明 PNG，存放 `public/assets/nft/`，每张不超过 400KB。

| 等级 | 金属结构 | 宝石与装饰 | 强调色 |
|---|---|---|---|
| 金 | 约 48px 双层鎏金框，内外倒角，柔和金色光晕 | 层叠叶片侧翼、皇冠徽饰、大号白青多切面钻石、四角小钻石、GOLD 铭牌 | `#f6d27a → #c8902f` |
| 银 | 约 40px 抛光冷银框，内圈细刻线 | 四角曲线卷草与蓝宝石、顶部大蓝宝石徽饰、中部小翼、SILVER 铭牌 | `#e6eef5 → #9fb3c4` |
| 铜 | 约 34px 古铜框，多层倒角 | 四角铆钉、顶部琥珀多切面宝石、小号 BRONZE 铭牌 | `#e3a77a → #9a5b34` |

- 金属采用 3–5 段反光渐变；每颗宝石包含中心台面、不同明暗的三角切面和白色高光，金级额外有四芒星闪光。三级在 256px 缩略图下依靠框宽、轮廓和装饰密度区分。
- `api/_lib/nft.js` 集中配置等级的 `framePath`、低透明度 `tint` 与 `panelGradient`；底图上叠暖金、冷银或红棕色调，成就进度条沿用等级强调色。
- 静态图：底图、等级色调、暗部、标题/信息面板、透明装饰框依次叠加。取消旧细描边及标题徽标；标题从顶部 176px 开始、左右安全边距至少 108px，面板底部距画布 140px，避开顶部徽饰、侧翼和底部铭牌。
- 展示页：正方形卡片居中，所有画面层局限于卡片内，按窗口短边等比缩放；装饰框位于最上层，不随底图推近而移动。继续尊重 prefers-reduced-motion。
- 验收：`scripts/nft/preview.mjs` 生成九张静态图与 `docs/nft-preview/grid.jpg`（行：草甸/湖畔/阿尔卑斯，列：金/银/铜），并检查 256px 缩略图、透明通道、PNG/JPEG 体积及展示页横竖屏。

## 元数据
- `attributes` 新增 `{ trait_type: 'Tier', value: 'Gold' | 'Silver' | 'Bronze' }`。
- 描述按 `best.verified` 写「服务器核实」或「玩家自报」；不可转让与非隶属声明保留。
- 图片缓存参数 `v` 继续使用更新时间，成绩变化后钱包能拿到新图。
