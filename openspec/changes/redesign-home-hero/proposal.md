# Change: 首页电影感开场

## Why
首页目前是加载进度条 + 几个按钮，第一印象平淡，体现不出这款游戏的质感和链上玩法。

## What Changes
- 加载完成后的首页改为电影感开场：
  - 背景沿用实时 3D 沙漠场景，开场时车辆缓慢驶过、推进器尾焰，镜头做慢速推拉（由现有场景相机按预设关键帧运动，加载期间保持现状）。
  - 大标题逐字点亮、扫光；副标题与语言切换淡入。
  - 模式大卡片：计时赛、太空之旅、赛季（即将推出）；多人房间按现有开关显示。卡片带实景预览（赛道预览图 / 太空循环视频），悬停时背景淡入对应场景画面并有光效，点击进入对应模式。
  - 底部链上实况条：已铸造 NFT 数、三条赛道当前最快圈与保持者（缩写地址）、最新一次上链，无数据或读取失败时隐藏。
  - 键盘可达（Tab/Enter），尊重 prefers-reduced-motion（关闭运镜与逐字动画），手机宽度改为纵向卡片。
- 视觉与动效模块由 Arc Studio 实现为独立模块（src/ui/home/），通过约定 API 接入现有外壳与 3D 场景。

## Impact
- Affected specs: home-hero（新增）
- Affected code: 新增 src/ui/home/；src/ui/ui.js 开始界面接入；src/game 中增加首页运镜预设；i18n 词条
- 不改游戏玩法、链上合约与服务端
