# Design: 比赛背景音乐与道具赛金币提速

## 背景音乐
- 素材：OpenGameArt「Driving Game Stylish Retro Beat」中的《Detroit Beat》，作者 ISAo，OGA-BY 3.0，时长 1:29。用 macOS `afconvert` 转为 AAC 128 kbps，放在 `public/assets/music/race-detroit.m4a`，按需懒加载，不阻塞赛道加载。（用户试听后由《Rush》改为此曲。）
- 混音链：媒体元素 → 高架 EQ（2.5 kHz 附近削 4 dB、6 kHz 以上削 3 dB，给漂移尖啸与喷气留空间）→ 避让增益 → 音乐总线（受音乐开关与静音控制）。
- 基础音量约为大厅音乐的 60%；暂停时降到 30% 并加低通；结算画面 1 秒淡出。
- 避让：推进器、漂移、氮气、金币小冲刺、被导弹或水雷击中任一激活时，避让增益在 80 ms 内降到 0.5；全部结束后 600 ms 内恢复到 1。由比赛音频模块每帧根据车辆状态驱动。
- 生命周期：倒计时结束（发车）时 1.5 秒淡入；循环播放（循环点做 200 ms 交叉淡化）；离开比赛或回到大厅时停止，大厅音乐照旧接管。
- 自动化测试与截图模式（`?capture`、`?still`）不播放音乐。

## 金币提速（仅多人道具赛）
- 模拟：`createSession` 新增选项 `coinBoost`，仅当房间模式为道具赛时由 `room-race.js` 和机器人传入 `true`。启用时车辆状态多一个 `coins`（0–10）：拾取金币 +1（封顶 10），极速乘以 `1 + 0.01 × coins`；为使普通直道的恒功率/风阻平衡速度确实达到该极速，启用时将风阻系数除以金币倍率的三次方，低速发动机推力不变；未启用时保留原计算表达式，golden 与 SIM_VERSION 不变。
- 小冲刺：每次拾取（包括满 10 枚）将独立状态 `coinDash` 刷新为 `max(coinDash, 0.4)` 秒，不累加时长、不改 `boostTime`。期间极速上限在金币倍率之后额外增加 `0.4 × T.boostSpeed`，推力增加 `0.4 × T.boostAcceleration`，直行和漂移均生效；关闭 `coinBoost` 时不创建、读取或递减该字段，重置车辆时清零。
- 追赶：拾取时补充的推进剂 = `coinFuel × (1 + rankFraction)`，`rankFraction` 为 0（第一）到 1（最后），由道具系统现有的名次数据提供。
- 掉落：导弹命中或触发水雷时 `coins = floor(coins / 2)`，并发出 `coinLoss` 事件（含掉落数量）。护盾挡下时不掉。
- 同步：车辆状态消息新增可选字段 `coins`（0–10 整数）与 `dash`（`coinDash > 0` 布尔值）。服务端只做范围与布尔类型校验后转发，旧客户端忽略该字段，兼容。
- 表现：
  - HUD：道具槽旁显示金币图标与「n/10」，拾取时数字跳动并弹出金色「+1」，满 10 时图标发光；速度数字旁以金色显示当前 `+n%`（0 枚隐藏）；每次拾取屏幕边缘金色辉光闪烁约 0.3 秒，减少动态偏好下取消辉光和金币动画，只保留 HUD 数字变化。
  - 车尾流光：自己与其他车按金币数增强，第 1 枚已有清晰细金线，使用深金色外缘和明亮金色线芯保证白天草地背景可见；宽度、长度和亮度随金币数逐级增加，满层时带金色粒子。
  - 冲刺：复用氮气尾焰、速度线及 FOV kick，强度约 50%；远端 `dash` 同样显示较弱尾焰；派生氮气音效，短促且音量较低，比赛音乐在小冲刺期间同样避让。
  - 掉落：车身位置向四周喷出对应数量的金币粒子（约 0.8 秒），HUD 显示红色「-n」。
- 平衡：持续加成最多 +10%，每次拾取的小冲刺在低中速也有即时推力反馈；配合掉落机制，让领先者成为导弹目标时更有代价。
