# Change: 往返纪念 NFT 与链上记录（Arc）

## Why
Mars Roadster 目前所有成绩和成就只存在浏览器本地存储里，换设备就没了，也无法向别人证明。把「完成一次地面 → 轨道 → 地面往返」这件事变成 Arc 上一枚好看的纪念 NFT，再配上公开的往返榜和成就记录，让玩家有收藏和比拼的理由，也让游戏真正用上 Arc。

## What Changes
- 新增 Arc 合约（Arc Studio 编写、测试、部署测试网；主网由用户钱包部署）：
  - 往返纪念 NFT：每个钱包最多一枚，不可转让（灵魂绑定），铸造免费、只付手续费
  - 每个钱包的往返最快用时（只保留最好成绩，低于物理下限的直接拒绝）
  - 每个钱包已解锁的成就（20 个开关压成一个数字，只增不减）
  - 一次交易完成：首次铸造 NFT + 更新最快成绩 + 合并新成就
- 游戏新增「往返用时」计时：从开始冲向太空到安全落回公路
- 本局成绩面板新增「连接钱包 → 铸造纪念 NFT / 更新链上记录」
- 新增「链上记录」面板：我的 NFT、我的链上成就、往返榜前 50
- 网站新增 NFT 元数据、合成图与动态展示页接口（底图与循环视频由游戏真车模型渲染，信息栏按链上数据实时合成）
- 页面与 NFT 描述注明「玩家自报成绩」和非隶属声明

## Impact
- Affected specs: onchain-records（新增）
- Affected code: src/game/index.js（计时、上报）、src/share/（成绩面板按钮）、新增 src/chain/（钱包与合约调用）、新增 api/nft/（元数据与图片）、新增 contracts/（Arc Studio 交付）、scripts/nft/（NFT 底图渲染）、public/assets/nft/
- 新增依赖：viem（钱包与合约调用）、@vercel/og 或同类（服务器端合成图片）
- 链上：Arc 测试网（5042002）先行，主网（5042）由用户钱包部署
