# Change: 独立个人主页

## Why
右上角弹窗里的「个人资料」信息挤在一起、缺少成就感，玩家铸造后没有一个值得反复打开、也值得分享的地方。

## What Changes
- 新增整页个人主页（`/?profile`，可带 `&address=0x…` 查看他人；无参数时显示当前钱包），右上角已连接时点地址进入；原「我的」弹窗标签由该页取代。
- 页面结构：
  - 顶部：由地址确定性生成的专属头像（渐变几何图形，不依赖外部服务）、缩写地址（可复制）、按成绩派生的车手称号、网络标识、断开连接。
  - NFT 展示：大尺寸首圈纪念 NFT，鼠标/触控倾斜的 3D 卡片与光泽效果；编号、首圈赛道与成绩、铸造日期、区块浏览器与 NFT 展示页链接；未铸造时显示剪影与「去计时赛跑进资格线」按钮。
  - 三条赛道成绩卡：最快单圈、核实状态、该赛道排名（读取排行榜计算）、与资格线和第 1 名的差距、「挑战我的影子」（进入该赛道并选中自己的录像）。
  - 成就墙：28 个成就格，已解锁高亮、未解锁暗显并可查看解锁条件（复用现有成就定义）。
  - 上链记录时间线：读取合约事件，按时间列出铸造、刷新最快圈、新增成就，附交易链接。
  - 排行榜页签：三条赛道前 50（仅已核实/全部），点任意玩家进入其个人主页。
- 右上角已连接时：点击地址进入个人主页；保留下拉中的「断开连接」「切换网络」。
- 页面复用赛车页的毛玻璃视觉，背景为暗色动态渐变 + 车辆剪影，适配手机宽度。

## Impact
- Affected specs: player-profile（新增）；wallet-hub 中「个人资料面板」行为由本页取代（实现时同步修订 add-wallet-hub）
- Affected code: 新增 src/profile/（页面、头像、成就墙、时间线）、src/main.js 路由、src/chain 读取合约事件、i18n 中英词条、测试
- 不改合约、服务端核实逻辑、录像与物理
