# Change: 影子赛与服务器核实成绩（路线阶段 1）

## Why
阶段 0 已上线，但链上成绩是「玩家自报」，谁都能提交一个假圈速；单人跑圈也缺少对手。竞速的按键录制与确定性物理已经就绪，可以低成本做两件事：服务器重放按键核实成绩，让排行榜可信；和自己或排行榜上其他人的「影子」同场跑，单人也有对手。不需要实时服务器。

## What Changes
- 新增影子赛：选图时可选影子（无 / 我的最佳 / 排行榜第 N 名），影子车半透明同场行驶，HUD 在每道检查点显示与影子的时间差（领先绿、落后红）。
- 「我的最佳」存在浏览器本地；排行榜影子从服务器下载。
- 新增核实接口 /api/verify：服务器用同一套模拟代码重放按键，算出各圈用时与竞速成就，确认后用核实者私钥签 EIP-712 Lap，并把该玩家该地图的最佳录像存入存储，供他人下载作影子。
- 新增 /api/ghost：按地图列出可下载的影子（排行榜前 N 名已核实的最佳录像），以及下载单条录像。
- 合约启用核实者（setVerifier），之后链上只接受带服务器签名的成绩；前端提交流程先请求签名再提交。**BREAKING**（对链上提交流程）：未核实的自报成绩不能再上链。
- 排行榜默认只显示已核实成绩。

## Impact
- Affected specs: ghost-race（新增）、onchain-records（修改：核实者从「预留」改为启用）
- Affected code: src/race/（影子会话、影子车外观、HUD 分段对比、选图界面的影子选项）、src/chain/（提交前取签名）、api/verify、api/ghost、api/_lib/（重放、签名、存储）、scripts/chain/（启用核实者）
- 新增基础设施：Vercel Blob 存储录像；Vercel 环境变量 VERIFIER_PRIVATE_KEY（敏感，由 Claude 生成并配置，Codex 不接触私钥）
