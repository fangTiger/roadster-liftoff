# Change: 右上角钱包入口、铸造成功反馈与「我的 NFT」查看

## Why
现在钱包只能在成绩面板和排行榜弹窗里连接；铸造成功后只有一行小字链接，铸造出的首圈纪念 NFT 在站内也没有地方看。玩家铸造完不知道成功没有、拿到了什么。

## What Changes
- 站点右上角常驻钱包按钮（首页与赛车页）：未连接显示「连接钱包」；已连接显示缩写地址和网络标识，点开下拉菜单：我的 NFT、在浏览器中查看地址、断开连接。网络不对时提示切换到 Arc 主网/测试网。
- 铸造/更新成功反馈：交易确认后成绩面板切换为成功状态（大号对勾、「首圈纪念 NFT 已铸造 #id」或「链上记录已更新」、NFT 缩略图、「查看我的 NFT」与「查看交易」按钮），同时弹出顶部提示；更新成绩同样提示。
- 「我的 NFT」面板：读取当前钱包的首圈纪念 NFT（每个钱包一枚、灵魂绑定），展示动态图片（/api/nft/image/{id}）、编号、首圈赛道与成绩、铸造日期、三条赛道最快单圈与核实状态、成就数，以及「在区块浏览器查看」和「打开 NFT 展示页」（/api/nft/view/{id}）。未铸造时给出引导：去计时赛跑进资格线。未连接时提示连接。
- 排行榜弹窗里原「我的首圈 NFT」区块改为复用同一张 NFT 卡片。

## Impact
- Affected specs: wallet-connection、onchain-records
- Affected code: src/chain/（新增 wallet-hub、nft-card 组件，race-panel 成功状态，race-board 复用卡片）、src/ui/ui.js 与 src/race/index.js 挂载入口、src/i18n 中英词条、相关测试
- 不改合约、不改服务端核实逻辑、不改录像与物理
