## ADDED Requirements
### Requirement: 铸造与更新成功反馈
系统 SHALL 在铸造或更新链上记录的交易确认后给出明确的成功反馈。

#### Scenario: 首次铸造成功
- **WHEN** 首圈纪念 NFT 铸造交易确认
- **THEN** 成绩面板切换为成功状态，显示「首圈纪念 NFT 已铸造 #编号」、NFT 缩略图、「查看我的 NFT」与「查看交易」按钮，并弹出顶部成功提示

#### Scenario: 更新成绩成功
- **WHEN** 已有 NFT 的玩家更新最快单圈或成就的交易确认
- **THEN** 显示「链上记录已更新」及新成绩，并弹出顶部成功提示

#### Scenario: 交易失败
- **WHEN** 交易被拒绝或回滚
- **THEN** 不显示成功状态，沿用现有错误提示并允许重试

### Requirement: 个人资料面板
系统 SHALL 在右上角提供个人资料面板，分「我的」与「排行榜」两个标签，汇总链上记录；选图页不再单独提供「链上记录」入口。

#### Scenario: 排行榜标签
- **WHEN** 用户切到「排行榜」标签
- **THEN** 显示三条赛道各自前 50 名，可切换「仅已核实 / 全部」；未连接钱包也可查看

#### Scenario: 选图页入口移除
- **WHEN** 用户在选图页
- **THEN** 不显示「链上记录」按钮；铸造成功状态中的「查看我的 NFT」打开个人资料面板的「我的」标签

#### Scenario: 我的标签
- **WHEN** 已连接钱包打开个人资料面板
- **THEN** 「我的」标签展示首圈纪念 NFT（见下列场景）、地址与网络、在区块浏览器查看地址、断开连接

#### Scenario: 已铸造
- **WHEN** 已连接钱包且该钱包持有首圈纪念 NFT
- **THEN** 显示动态图片、编号、首圈赛道与成绩、铸造日期、三条赛道最快单圈及核实状态、成就数，并提供区块浏览器与 NFT 展示页链接

#### Scenario: 未铸造
- **WHEN** 已连接钱包但尚未铸造
- **THEN** 显示空状态与引导「去计时赛跑进资格线即可铸造」，并可直接进入赛道选择

#### Scenario: 未连接
- **WHEN** 用户未连接钱包时打开面板
- **THEN** 提示连接钱包并提供连接按钮

#### Scenario: 图片加载失败
- **WHEN** NFT 图片接口暂不可用
- **THEN** 显示占位图与文字信息，不影响其余数据展示
