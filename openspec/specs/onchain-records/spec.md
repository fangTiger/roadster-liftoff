# onchain-records Specification

## Purpose
玩家在 Arc 上铸造不可转让的纪念 NFT、记录成绩与成就；网站提供 NFT 元数据、静态图与动态展示页。测试网与主网均已部署赛道合约 V2（MarsRoadsterRacing，主网地址 0xE0D2c19988a6fC90806B56De797Fc4D107946526），成绩由服务端核实者签名。
## Requirements
### Requirement: 链上成就记录
系统 SHALL 以 32 位位图为每个持有 NFT 的钱包记录已解锁的成就，只增不减；当前使用第 0–27 位。

#### Scenario: 合并新成就
- **WHEN** 持有 NFT 的钱包提交包含新成就的位图
- **THEN** 链上位图与之按位或合并，已有成就保留

#### Scenario: 无可更新内容
- **WHEN** 提交的用时不更快且没有新成就
- **THEN** 交易被拒绝

### Requirement: 游戏内铸造与更新
游戏 SHALL 在竞速模式赛后成绩面板提供连接钱包并铸造或更新链上记录的入口，且没有可更新内容时不发交易。

#### Scenario: 进入资格线且未持有 NFT
- **WHEN** 本局最快单圈不超过资格线，且连接的钱包未持有 NFT
- **THEN** 面板显示「铸造首圈纪念 NFT」，成功后显示区块浏览器链接

#### Scenario: 未进资格线且未持有 NFT
- **WHEN** 本局最快单圈超过资格线，且钱包未持有 NFT
- **THEN** 面板显示资格线与差距，不显示铸造按钮

#### Scenario: 无可更新内容
- **WHEN** 钱包已持有 NFT，本局成绩不比链上更快且没有新成就
- **THEN** 面板提示链上记录已是最新，不发起交易

#### Scenario: 交易失败
- **WHEN** 余额不足、用户取消或网络错误
- **THEN** 面板显示对应原因，游戏继续正常运行

### Requirement: 链上记录面板
游戏 SHALL 提供链上记录面板，显示玩家自己的首圈 NFT、各赛道最快单圈、链上成就数（n/28），以及草甸环线、湖畔环线、阿尔卑斯环线三张地图各自的排行榜前 50 名，并标注为玩家自报成绩。

#### Scenario: 查看排行榜
- **WHEN** 玩家打开链上记录面板
- **THEN** 显示按最快单圈升序排列的前 50 名（钱包缩写、用时、日期），并注明「玩家自报成绩」

### Requirement: NFT 元数据与图片
网站 SHALL 为每枚 NFT 提供元数据、静态图和动态展示页，内容为首圈用时、最快单圈、赛道名、成就数和等级；外观 SHALL 按首圈赛道选用该赛道专属底图，并按该赛道链上最快单圈判定金、银、铜三档等级，套用对应的原创宝石装饰边框、色调和等级铭牌。

#### Scenario: 钱包读取 NFT
- **WHEN** 钱包或区块浏览器请求某枚 NFT 的元数据
- **THEN** 返回名称（含至少四位补零编号）、描述（含成绩是否经服务器核实、不可转让和非隶属声明）、静态图地址、动态展示页地址和属性（赛道、等级、首圈用时、最快单圈、成就数、铸造日期、网络）

#### Scenario: 按赛道区分底图
- **WHEN** 请求首圈在草甸、湖畔或阿尔卑斯的 NFT 静态图或展示页
- **THEN** 使用该赛道的专属底图；未知赛道使用通用底图
- **AND** 草甸无金币，湖畔明显可见湖面，阿尔卑斯可见断桥或山体；车辆以斜侧角度入画，无 HUD；湖面是 NFT 摄影布景，不能改动游戏物理或赛道定义

#### Scenario: 等级判定
- **WHEN** 该赛道链上最快单圈不超过金级线、不超过银级线或高于银级线
- **THEN** 分别显示金、银、铜等级；没有最快圈记录时按首圈用时判定

#### Scenario: 成绩更新后图片变化
- **WHEN** 玩家在首圈赛道上传更快的最快单圈
- **THEN** 之后请求的静态图和展示页显示新的最快单圈与对应等级，首圈用时和底图不变

#### Scenario: 核实状态
- **WHEN** 该赛道最快圈已由服务器核实
- **THEN** 静态图底部显示 VERIFIED，元数据描述写明成绩经服务器核实；未核实时显示 SELF-REPORTED

#### Scenario: 无效或不存在的编号
- **WHEN** 请求的编号格式无效或尚未铸造
- **THEN** 元数据、静态图与展示页接口分别返回 JSON 400 或 JSON 404；RPC 故障返回不缓存的 JSON 503

#### Scenario: 宝石边框和等级辨识
- **WHEN** 请求任一等级的静态图或展示页
- **THEN** 最上层使用对应 `frame-{gold,silver,bronze}.png` 透明边框；金级双层框、皇冠钻石与大侧翼，银级卷草蓝宝石与小侧翼，铜级铆钉琥珀；底部各有等级铭牌
- **AND** 等级色调和面板渐变保持一致，文字避开装饰；展示页正方形居中且按比例缩放，256px 缩略图可区分三档

### Requirement: 首次资格圈纪念 NFT
系统 SHALL 允许首次在资格线内跑完一圈的钱包在 Arc 上铸造一枚灵魂绑定纪念 NFT；每个钱包最多一枚，NFT 记录首圈的赛道、用时和时间，之后不再改变。

#### Scenario: 首次铸造
- **WHEN** 未持有 NFT 的钱包提交一个不超过该赛道资格线的单圈
- **THEN** 合约铸造一枚新编号的 NFT，记录首圈，并把该成绩记为此赛道最快单圈

#### Scenario: 未进资格线
- **WHEN** 未持有 NFT 的钱包提交超过资格线的单圈
- **THEN** 交易被拒绝，不铸造 NFT

#### Scenario: 不能重复铸造
- **WHEN** 已持有 NFT 的钱包再次提交
- **THEN** 不铸造新 NFT，首圈记录不变，只更新最快单圈和成就

#### Scenario: 不可转让
- **WHEN** 任何人调用转让或授权函数
- **THEN** 交易被拒绝

### Requirement: 赛道最快单圈
系统 SHALL 按（钱包，赛道）保存最快单圈，只在新成绩更快时更新，并拒绝低于作弊下限或赛道未开放的提交。

#### Scenario: 成绩更快
- **WHEN** 持有 NFT 的钱包提交短于其该赛道最快单圈的用时
- **THEN** 最快单圈更新为新用时

#### Scenario: 成绩过快
- **WHEN** 提交的用时低于该赛道作弊下限
- **THEN** 交易被拒绝

#### Scenario: 下限只能调高
- **WHEN** 合约管理员尝试把某赛道的作弊下限调低
- **THEN** 交易被拒绝

#### Scenario: 赛道未开放
- **WHEN** 提交的赛道资格线为 0
- **THEN** 交易被拒绝

### Requirement: 服务器签名核实（预留）
合约 SHALL 支持设置核实者地址；设置后，每次提交必须附带核实者对（玩家、赛道、用时、成就、截止时间）的有效签名，并标记该成绩已核实。阶段 1 起，前端提交前先向 /api/verify 取得签名，链上排行榜默认只显示已核实成绩。

#### Scenario: 未设置核实者
- **WHEN** 核实者地址为空
- **THEN** 提交不需要签名，成绩标记为未核实

#### Scenario: 签名无效或过期
- **WHEN** 已设置核实者，而提交的签名不匹配或已过截止时间
- **THEN** 交易被拒绝

#### Scenario: 核实后上链
- **WHEN** 玩家完赛后在成绩面板铸造或更新
- **THEN** 前端先取得服务器签名再提交，链上成绩标记为已核实

### Requirement: 铸造与更新成功反馈
系统 SHALL 在铸造或更新链上记录的交易确认后给出明确的成功反馈。

#### Scenario: 首次铸造成功
- **WHEN** 首圈纪念 NFT 铸造交易确认
- **THEN** 成绩面板切换为成功状态，显示「首圈纪念 NFT 已铸造 #编号」、NFT 缩略图、「查看个人主页」与「查看交易」按钮，并弹出顶部成功提示

#### Scenario: 更新成绩成功
- **WHEN** 已有 NFT 的玩家更新最快单圈或成就的交易确认
- **THEN** 显示「链上记录已更新」及新成绩，并弹出顶部成功提示

#### Scenario: 交易失败
- **WHEN** 交易被拒绝或回滚
- **THEN** 不显示成功状态，沿用现有错误提示并允许重试

### Requirement: 个人主页入口
系统 SHALL 通过右上角地址进入独立个人主页（/?profile），原个人资料面板的「我的」标签由该页取代（见 add-profile-page 的 player-profile）；排行榜进入该页的排行榜页签（/?profile&tab=leaderboard）。选图页不再单独提供「链上记录」入口。

#### Scenario: 排行榜标签
- **WHEN** 用户切到「排行榜」标签
- **THEN** 显示三条赛道各自前 50 名，可切换「仅已核实 / 全部」；未连接钱包也可查看

#### Scenario: 选图页入口移除
- **WHEN** 用户在选图页
- **THEN** 不显示「链上记录」按钮；铸造成功状态中的「查看个人主页」进入独立个人主页（/?profile）

#### Scenario: 个人主页
- **WHEN** 已连接钱包点击右上角地址
- **THEN** 独立个人主页展示首圈纪念 NFT（见下列场景）、地址与网络、在区块浏览器查看地址、断开连接

#### Scenario: 已铸造
- **WHEN** 已连接钱包且该钱包持有首圈纪念 NFT
- **THEN** 显示动态图片、编号、首圈赛道与成绩、铸造日期、三条赛道最快单圈及核实状态、成就数，并提供区块浏览器与 NFT 展示页链接

#### Scenario: 未铸造
- **WHEN** 已连接钱包但尚未铸造
- **THEN** 显示空状态与引导「去计时赛跑进资格线即可铸造」，并可直接进入赛道选择

#### Scenario: 未连接
- **WHEN** 用户未连接钱包时打开 /?profile
- **THEN** 提示连接钱包并提供连接按钮

#### Scenario: 图片加载失败
- **WHEN** NFT 图片接口暂不可用
- **THEN** 显示占位图与文字信息，不影响其余数据展示
